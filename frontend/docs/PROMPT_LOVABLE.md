# Education Atlas

Crie uma landing page completa, moderna, acadêmica e profissional para um projeto de TCC-II de Data Science chamado provisoriamente:

"Observatório Inteligente da Educação Superior"

IMPORTANTE:

Esta página será utilizada como referência visual e base inicial para o frontend definitivo do projeto.

O produto é uma plataforma de análise da Educação Superior brasileira utilizando dados do Censo da Educação Superior do INEP.

O sistema futuro combinará:

- análise estatística;

- dados de Instituições de Ensino Superior (IES);

- dados de cursos;

- análise municipal;

- mapas interativos;

- visualização geoespacial;

- dashboards;

- comparação territorial;

- Inteligência Artificial;

- consultas aos dados através de linguagem natural.

Neste momento, desenvolva principalmente a LANDING PAGE e uma PREVIEW VISUAL do produto.

Não implemente backend real.

Não implemente banco de dados.

Não implemente autenticação.

Não implemente integração real com IA.

Não crie complexidade desnecessária.

Os dados exibidos nesta versão devem ser claramente tratados como exemplos visuais/placeholders quando não forem informações confirmadas.

================================================================

18. ANIMAÇÕES

================================================================

Usar apenas microanimações.

Permitido:

- fade/slide muito discreto ao entrar no viewport;

- hover suave;

- pequenas transições;

- números/cards com animação mínima;

- mapa com movimento visual sutil.

Não usar:

- parallax exagerado;

- elementos voando;

- animações constantes;

- efeitos que prejudiquem leitura.

Respeitar prefers-reduced-motion.

22. RESULTADO ESPERADO

================================================================

Quero que o primeiro impacto visual da página transmita:

"Esta é uma plataforma acadêmica séria de Data Science e inteligência territorial."

E não:

"Este é apenas mais um dashboard."

A landing page deve ter forte identidade visual própria.

O mapa e a visualização de dados devem ser protagonistas.

A página deve criar uma transição natural entre:

Pesquisa

→ Dados

→ Território

→ Visualização

→ Inteligência Artificial.

Use criatividade para melhorar a composição, desde que preserve esses princípios.

Antes de finalizar:

- revise responsividade;

- revise consistência de espaçamento;

- revise hierarquia tipográfica;

- remova elementos decorativos desnecessários;

- garanta que não existam estatísticas fictícias apresentadas como reais;

- garanta que a landing page pareça coesa, institucional e moderna.
